## Modalidad de trabajo

La Evaluación 1 se desarrolla de manera individual, previa comunicación y autorización del docente de la asignatura. Debido a esta modalidad, las actividades de análisis, desarrollo, implementación, pruebas y documentación son realizadas por una única responsable.

## Organización del trabajo

| Actividad | Estado | Evidencia |
|---|---|---|
| Análisis del proceso actual de ventas | Completado | Modelo BPMN AS-IS |
| Diseño de propuesta de mejora | Completado | Modelo BPMN TO-BE |
| Implementación del proceso | Completado | Flowable |
| Configuración de formularios | Completado | Flowable Forms |
| Configuración de decisiones y rutas | Completado | Proceso TO-BE |
| Pruebas de ejecución | Completado | Carpeta `evidencias-flowable` |
| Desarrollo de Web Service | Completado | API REST Spring Boot |
| Pruebas del Web Service | Completado | Postman |
| Control de versiones | Completado | Git y GitHub |
| Documentación del proyecto | Completado | README |

## Roles y responsabilidades

Al tratarse de un trabajo individual, la responsable del proyecto asumió las siguientes funciones:

- Análisis del proceso actual de Mapuescuela.
- Modelamiento del proceso AS-IS.
- Diseño del proceso mejorado TO-BE.
- Implementación y configuración del proceso en Flowable.
- Creación y configuración de formularios.
- Ejecución y prueba de diferentes rutas del proceso.
- Desarrollo de una API REST mediante Java y Spring Boot.
- Pruebas de los endpoints mediante Postman.
- Gestión del repositorio y control de versiones mediante Git y GitHub.
- Organización de evidencias y documentación del proyecto.

## Seguimiento del desarrollo

El proyecto se desarrolló de manera progresiva, verificando el funcionamiento de cada componente antes de continuar con las siguientes etapas.

Durante el desarrollo se realizaron pruebas del proceso implementado en Flowable, incluyendo formularios, decisiones y diferentes rutas de ejecución. También se verificó el funcionamiento de los servicios web mediante Postman.

Los avances fueron respaldados mediante commits en GitHub, manteniendo separados y organizados los modelos BPMN, el código fuente, las evidencias de ejecución y la documentación del proyecto.

## Evidencias de seguimiento

El repositorio contiene:

- Modelos BPMN AS-IS y TO-BE.
- Imágenes de ambos modelos para su visualización.
- Código fuente de la API REST.
- Evidencias de ejecución del proceso en Flowable.

Este registro permite evidenciar la organización, avance y seguimiento realizado durante el desarrollo individual de la evaluación.
